Còpies de seguretat a Windows: tornar enrere

Set apartats sobre com es planifica, es fa i es restaura una còpia de seguretat a Windows Server, amb Windows Server Backup i Cobian Reflector. Els exemples segueixen la pràctica AEA3: la carpeta Dades amb els fitxers file1 a file5. El progrés es guarda en aquest navegador.

    Completa, incremental o diferencial

    Què es copia cada vegada, i què et caldrà el dia que ho hagis de restaurar.

    Una bona política de còpies defineix què es copia, quan es copia i com es gestionen les còpies al llarg del temps. Hi ha tres tipus de còpia:

    Completa

    Copia tots els fitxers seleccionats. Ocupa més i és lenta, però restaurar és molt fàcil: només cal aquesta còpia.

    Incremental

    Copia només el que ha canviat des de l'última còpia, sigui del tipus que sigui. Molt ràpida i petita, però per restaurar cal la completa i totes les incrementals posteriors.

    Diferencial

    Copia el que ha canviat des de l'última completa. Cada dia ocupa una mica més, però per restaurar només cal la completa i l'última diferencial.

    Com sap Windows què ha canviat? fora de la presentació

    Una marca petita a cada fitxer: l'atribut d'arxiu.

    A Windows cada fitxer té l'atribut d'arxiu (la lletra A a les propietats). Quan crees o modifiques un fitxer, Windows l'activa. Moltes eines de còpia, com Cobian Reflector amb l'opció «Usar el atributo de archivo», el fan servir per saber què han de copiar:

    TipusQuè copiaQuè fa amb l'atribut
    CompletaTotEl desactiva a tots els fitxers
    IncrementalEls fitxers amb l'atribut activatEl desactiva: el pròxim cop ja no es copiaran
    DiferencialEls fitxers amb l'atribut activatNo el toca: es tornaran a copiar fins a la pròxima completa

    Aquesta petita diferència explica per què les diferencials creixen dia rere dia i les incrementals no.

    Windows Server Backup

    L'eina de còpies que porta Windows Server.

    Primer cal instal·lar-la: al Server Manager, Add Roles and Features → Features → Windows Server Backup. Després l'obres des de les eines administratives. Des del panell Local Backup tens tres accions: Backup Schedule (còpia programada), Backup Once (còpia ara, una sola vegada) i Recover (restaurar).

    On guardes les còpies

    Disc dedicat (recomanat)

    El disc es formata i queda reservat per a les còpies. No apareix a l'Explorador de fitxers, cosa que el protegeix i permet endur-se'l fora.

    Un volum

    Si no pots dedicar un disc sencer. El rendiment d'aquell volum pot baixar fins a un 200 % mentre es fa la còpia.

    Carpeta de xarxa

    Les còpies no queden al servidor, però només n'hi ha una: cada còpia nova sobreescriu l'anterior.

    Si guardes la còpia en un DVD, només podràs recuperar volums sencers, no fitxers ni carpetes concrets.

    Cobian Reflector

    Un programa gratuït per programar còpies completes, incrementals i diferencials.

    Windows Server Backup és senzill, però per fer còpies incrementals cada pocs minuts a l'apartat 2 de la pràctica es fa servir Cobian Reflector. Cada tasca es configura per pestanyes:

    General

    Nom de la tasca i tipus de còpia: completa, incremental, diferencial o tasca buida.

    Fitxers

    L'origen (què copies) i el destí (on ho guardes).

    Horari

    Quan s'executa: un cop, diari, setmanal, mensual o amb temporitzador cada X minuts.

    Opcions

    Subdirectoris, còpies noves separades amb data, atribut d'arxiu i instantània de volum (VSC) per copiar fitxers oberts.

    A l'exemple de la documentació, el destí és l'Escriptori del mateix disc C: on hi ha la carpeta Dades. La pràctica funciona, però si aquell disc s'espatlla perds alhora les dades i les còpies.

    Restaurar: trobar la versió bona

    Una còpia només és útil si saps trobar-hi el que busques.

    A la pràctica, Cobian va fer una còpia cada minut mentre modificaves els fitxers. Com que tenia activada l'opció de còpies separades, cada còpia és una carpeta amb la data i l'hora al nom. La primera és la completa; les altres només tenen el que havia canviat.

    Per tornar la carpeta a com estava en un moment concret, has de restaurar la completa i, en ordre, totes les incrementals fins a aquell moment. Per recuperar un fitxer concret, n'hi ha prou de trobar la còpia que en conté la versió que vols.

    L'assistent de recuperació

    Recover: d'on, quina data, què i cap a on.

    L'assistent Recover de Windows Server Backup et demana, per ordre: on és la còpia (aquest servidor o una altra ubicació), quin disc la conté, de quina data i hora, què vols recuperar (fitxers i carpetes, volums, aplicacions o l'estat del sistema), quins elements concrets i les opcions de recuperació.

    Destí

    Ubicació original (on era el fitxer) o una altra ubicació que tries tu.

    Si el fitxer ja hi és

    Crear còpies per tenir les dues versions, sobreescriure la versió actual o no recuperar els que ja existeixen.

    Seguretat

    Restaurar els permisos (ACL) que tenia el fitxer quan es va fer la còpia.

    Fes sempre simulacres de restauració. Una còpia que mai no has provat de restaurar és només una esperança.

    La regla 3-2-1

    Quantes còpies, en quins suports i on.

    3 còpies

    Almenys tres còpies de les dades: l'original i dues més. Si una falla, encara en queden dues.

    2 suports diferents

    Almenys dos tipus de suport (disc local, NAS, núvol, cinta…) perquè una mateixa fallada no les afecti totes.

    1 fora

    Una còpia fora de la ubicació principal, contra incendis, inundacions o robatoris.
